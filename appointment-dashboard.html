❓ What the codes mean
Responses — where each answer came from
A( ) — Response from the patient app (patient self-entered).
R( / ) — Robo auto-call asking the set questions (answered / asked).
S( ) — Call made by the support care manager (live human).
All( ) — All responses across every source combined.
OOR( ) — Out-of-range readings that need clinical attention.
Services — three different things, shown separately
Enrollment — RPM / RTM / CCM programs the patient is enrolled in.
Consent: TM — patient gave permission for telemedicine.
Flag: Prac F/U — open problem the practice must resolve.
Verified Eligible — RPM/CCM/RTM eligibility confirmed (≠ enrolled).
Eligibility — two checks
Eligibility (CI) — internal Complete-Information review.
Waystar — real-time 270/271 payer eligibility.
Other
Source: MCW — referral source value.
Reg Status — Registered-EMR · Enrolled-Services · Enrollment In Progress.
Can't Import BlueButton — Medicare Blue Button 2.0 claims import failed for this patient.
